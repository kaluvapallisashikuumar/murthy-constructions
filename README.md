# Murthy Constructions

A modern, responsive website created for **Murthy Constructions**, a masonry and construction business.

The website is designed to present the company's construction services, showcase completed work, provide business information, and make it easy for customers to get in touch.

**Murthy Constructions** is a website built for a family-owned masonry/construction business.

## 🚀 Running the Project

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Go into the project folder:

```bash
cd murthy-constructions
```

Then open the project in your preferred code editor.

If it is a simple HTML/CSS/JavaScript project, you can open `index.html` directly in a browser.

If the project uses a framework such as React or Vite, install the dependencies:

```bash
npm install
```

Then start the development server:

```bash
npm run dev
```
